# Liftoffle brand kit

**Liftoffle** · *name the thing nobody else will.*
The daily rare-answer word game. Play solo, or race your friends.

## What's inside

### `logo/` (every logo comes as SVG + PNG at 2×)
| File | Use it for |
|---|---|
| `liftoffle-mark.svg/.png` | App icon, profile pictures, anywhere square |
| `liftoffle-mark-transparent.svg/.png` | The rocket and orbit without the tile, on your own background |
| `liftoffle-mark-mono-black` / `-mono-white` | One-colour print: stamps, stickers, embroidery, laser |
| `liftoffle-logo-horizontal-dark` / `-light` | Website headers, slides, email signatures |
| `liftoffle-logo-tagline-dark` / `-light` | Horizontal logo with the tagline |
| `liftoffle-logo-stacked-dark` / `-light` | Square-ish spaces: posters, merch, splash screens |
| `liftoffle-wordmark-dark` / `-light` | Text-only logo |

"-dark" = for dark backgrounds (light text). "-light" = for light backgrounds (dark text).
All text in the SVGs is converted to outlines, so they look the same everywhere with no font installed.

### `icons/`
`favicon-16/32/48.png`, `apple-touch-icon-180.png` (full-bleed, no transparent corners, as iOS wants), `icon-192/512/1024.png` (Android, PWA, app stores).

### `banners/`
| File | Size | Where |
|---|---|---|
| `liftoffle-og-image-1200x630.png` | 1200×630 | Link previews: WhatsApp, Slack, Discord, LinkedIn, Facebook, X |
| `liftoffle-x-header-1500x500.png` | 1500×500 | X / Twitter profile header (bottom-left kept clear for the profile photo) |
| `liftoffle-linkedin-banner-1584x396.png` | 1584×396 | LinkedIn page or profile banner |
| `liftoffle-social-square-1080x1080.png` | 1080×1080 | Instagram / feed post |
| `liftoffle-story-1080x1920.png` | 1080×1920 | Instagram / WhatsApp story |

`src/` holds the editable banner templates (plain HTML/CSS). Change the text, then open in Chrome
at the listed size and take a screenshot to re-export.

### `fonts/`
**Space Mono** (Bold for the wordmark and headlines, Regular for taglines and labels), by Colophon Foundry
for Google Fonts. Free for any use under the SIL Open Font License (`OFL.txt`, which must travel with the font files).

## Quick rules
- Write it **Liftoffle** in text, one word with a capital L. The logo itself is all caps with "LE" in pink.
- Leave clear space around the logo of at least the height of the "L".
- Don't recolour, stretch, rotate, outline or add shadows to the logo.
- Smallest sizes: mark 16 px (use `favicon-16.png`), horizontal logo 120 px wide.
